**Vale Consistency — steal-a-part.** Live repository: `vale-cli/vale`; [MIT, LICENSE:1–13](https://github.com/vale-cli/vale/blob/cf649e6e7089804dd1bad745fdcd12aeee7f7aae/LICENSE#L1-L13); last pushed 2026-09-10 ([API snapshot:70](/private/var/folders/mf/9v804k_57lq30kwtlr7468xr0000gn/T/terse-four-leads.sKzrox/vale-metadata.json:70)).

- **Mechanism:** an author supplies an `either` map of mutually exclusive regex pairs. Vale compiles one named-group alternation per pair, with word boundaries by default; `nonword` removes boundaries and `ignorecase` enables case-insensitive matching. It does **not discover alternative spellings automatically** ([internal/check/consistency.go:19–77](https://github.com/vale-cli/vale/blob/cf649e6e7089804dd1bad745fdcd12aeee7f7aae/internal/check/consistency.go#L19-L77)).
- Each processed block contributes matched group IDs to the file’s `Sequences` history. If the current block contains a match and both alternatives have appeared in that history, it creates one alert per pair for that block. Thus evidence accumulates across blocks within a file; neither spelling is designated correct ([consistency.go:84–118](https://github.com/vale-cli/vale/blob/cf649e6e7089804dd1bad745fdcd12aeee7f7aae/internal/check/consistency.go#L84-L118), [internal/core/file.go:27–34](https://github.com/vale-cli/vale/blob/cf649e6e7089804dd1bad745fdcd12aeee7f7aae/internal/core/file.go#L27-L34)).
- Reporting has a quirk: it takes the last captured match’s span, then locates the matched text without anchoring; the reported position need not mark the first conflicting occurrence ([consistency.go:106–113](https://github.com/vale-cli/vale/blob/cf649e6e7089804dd1bad745fdcd12aeee7f7aae/internal/check/consistency.go#L106-L113)).
- **Cost, from source rather than a benchmark:** one regex scan per pair per block, storage proportional to recorded captures, and up to two linear searches through accumulated history per matching pair/block; history searches can become quadratic as blocks accumulate ([consistency.go:90–103](https://github.com/vale-cli/vale/blob/cf649e6e7089804dd1bad745fdcd12aeee7f7aae/internal/check/consistency.go#L90-L103), [internal/core/util.go:245–271](https://github.com/vale-cli/vale/blob/cf649e6e7089804dd1bad745fdcd12aeee7f7aae/internal/core/util.go#L245-L271)). Arbitrary regexes also incur backtracking costs; a general linear-time guarantee would be false ([internal/regex/regex.go:1–20](https://github.com/vale-cli/vale/blob/cf649e6e7089804dd1bad745fdcd12aeee7f7aae/internal/regex/regex.go#L1-L20)).
- **Shipped usage: YES.** `proselint` v0.3.4 ships [proselint/Spelling.yml:1–17](https://github.com/vale-cli/proselint/blob/v0.3.4/proselint/Spelling.yml#L1-L17): `extends: consistency`, severity `error`, case-insensitive, twelve pairs including `advisor/adviser`, `centre/center`, and `colour/color`. The scan covered all **21 registered release archives, 1,157 YAML files**, finding this one direct instantiation; its released bytes matched the Contents API ([package-scan.txt:44–46](/private/var/folders/mf/9v804k_57lq30kwtlr7468xr0000gn/T/terse-four-leads.sKzrox/package-scan.txt:44)).
- **Measures / practice:** deterministic co-occurrence of configured alternatives, not comprehension. Suitable as an advisory audit step: `colour` and `color` can preserve every reader-test answer while violating naming consistency. Borrow the pair check, with pinned rules and explicit scope; it cannot detect unlisted alternatives or factual contradictions ([Spelling.yml:5–17](https://github.com/vale-cli/proselint/blob/v0.3.4/proselint/Spelling.yml#L5-L17), [consistency.go:90–118](https://github.com/vale-cli/vale/blob/cf649e6e7089804dd1bad745fdcd12aeee7f7aae/internal/check/consistency.go#L90-L118)).

It is an operational prompt protocol, not validated comprehension measurement; current CI only validates plugin structure ([bloat-auditor.md:24–26](https://github.com/Battle-Creek-LLC/tamos/blob/66f5704236a6cdb6c0fe4c7586eb2acc17fe57c2/agents/bloat-auditor.md#L24-L26), [commands/tamos-validate.md:50–80](https://github.com/Battle-Creek-LLC/tamos/blob/66f5704236a6cdb6c0fe4c7586eb2acc17fe57c2/commands/tamos-validate.md#L50-L80), [.github/workflows/validate.yml:7–17](https://github.com/Battle-Creek-LLC/tamos/blob/66f5704236a6cdb6c0fe4c7586eb2acc17fe57c2/.github/workflows/validate.yml#L7-L17)).
