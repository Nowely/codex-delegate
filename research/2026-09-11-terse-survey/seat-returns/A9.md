Convergence threshold: **at least 8/10 independent projects (80%)**. Counts below are documents, not sections or repeated examples; parentheses give README/documentation-page counts.

1. **10/10 (5R+5D): purpose/task context precedes executable examples.** Each supplies a concrete command or program, with a reason or task framing before it; the semantic framing judgment was checked manually.
2. **9/10 (4R+5D): a code block arrives within the first 400 counted words.** ripgrep is the exception; its earlier commands appear inside comparison tables. This describes the requested window, not a proposed writing limit.
3. **9/10 (5R+4D): explicit headings begin before body prose.** Astro supplies its titles through metadata/components instead.
4. **9/10 (5R+4D): lists carry some content.** Rust’s selected tutorial uses prose and code without lists.
5. **9/10 (5R+4D): estimated median prose paragraph is one sentence.** Rust’s is two; fragments and API field labels affect this statistic, especially pageres.
6. **9/10 (5R+4D): no collapsible blocks.** Vite alone uses one; collapsibility is optional in this sample.
7. **8/10 (5R+3D): an installation route exists on the page**, either instructions or an explicit link. Rust and FastAPI’s selected lesson pages omit installation instructions.
8. **8/10 (4R+4D): no tables.** The exceptions use tables for actual comparisons: ripgrep benchmarks and Vite’s template/language matrix.

Singletons, each **1/10**:

- ripgrep: six benchmark tables before the first fenced code example.
- pageres: heading depth five, reflecting an embedded API reference with named options.
- Astro: no explicit body heading; page organization lives in metadata and components.
- HTTPie: a repository-star-loss story interrupts the opening before getting-started links.

The widely repeated belief **“good documentation never skips heading levels” is not supported as a convergent practice here**: uv, Vite and FastAPI skip levels; only 6/9 explicit outlines obey it. This says nothing about the accessibility consequences of those jumps.
My expectations of uniform heading ladders and installation commands near the top were refuted: only **2/5 READMEs** put an install command within the 400-word window. I also expected richer table use; only **2/10** use any. One-sentence-per-source-line formatting likewise does not converge.
For terse, the useful candidates are task framing, discoverable routes and contextual examples. Frequency alone does not establish improved comprehension; test those candidates against reader answers. This census supports neither a universal prose/code ratio nor sentence-word ceilings or punctuation gates.
